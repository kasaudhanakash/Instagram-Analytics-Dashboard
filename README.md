

# Instagram Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard created to analyze Instagram engagement performance.

## Features
- Total Likes Analysis
- Total Comments Analysis
- Total Shares Analysis
- Total Reach Analysis
- Engagement Rate Analysis
- Traffic Source Performance
- Media Type Performance
- Content Category Performance

## Tools Used
- Power BI
- Microsoft Excel / CSV
- Data Visualization

## Dashboard Insights
- Compare engagement across media types
- Identify top-performing content categories
- Analyze traffic source effectiveness
- Track overall Instagram performance
